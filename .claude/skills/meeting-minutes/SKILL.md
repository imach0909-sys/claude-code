# 会議音声 → 議事録 作成スキル

会議の録音ファイルを入力に、(1) ローカルで文字起こし＋話者分離したトランスクリプトを作り、
(2) それを既存スキル **`precise-minute-taking`** に渡して詳細な議事録を生成する。

文字起こし・話者分離はローカルの無料モデルで動くため追加課金は発生しない。
議事録の文章生成は Claude Code 自身（＝定額の範囲）が `precise-minute-taking` を通じて行う。

## このスキルが受け取る入力

ユーザーから以下を集める。足りないものは作業前に質問する。

- **音声ファイル**: mp3 / wav / m4a などのパス（必須）
- **日時情報**: 会議の開催日時（例: 2026-06-23 14:00〜15:00）
- **出席者情報**: 氏名の一覧。可能なら「話者A=田中」のように話者ラベルとの対応も。
  分からなければ後述のサマリを使って推定・確認する。
- **説明者情報**: 話題ごとの主たる説明者（誰がどの議題を説明したか）。
  全体を通して特定の説明者がいる場合はその氏名。

## 手順

### 1. 事前確認

リポジトリ内の `speaker-transcriber/` を使う。実行環境を確認する。

- `HF_TOKEN` 環境変数が設定されているか（話者分離 pyannote に必須・無料トークン）。
  未設定なら、`https://hf.co/settings/tokens` での取得と
  `https://hf.co/pyannote/speaker-diarization-3.1` の規約同意を案内する。
- `ffmpeg` が入っているか（mp3 デコード用）。
- 依存が未インストールなら `pip install -r speaker-transcriber/requirements.txt` を案内する。

### 2. 文字起こし＋話者分離を実行

出席者の人数が分かっていれば `--speakers` に渡すと精度が安定する。

```bash
python speaker-transcriber/run.py <音声ファイル> \
    --model small --speakers <出席者数> --out transcript.txt
```

- 文字起こし精度が物足りなければ `--model medium` または `--large-v3` に上げる。
- 標準出力には、トランスクリプト本文に加えて「話者サマリ（話者ごとの発話数・
  合計時間・性別・発話比率）」が出る。これを次のステップで使う。

### 3. 話者ラベル → 出席者名のマッピング

`run.py` が出力した話者サマリと、ユーザーから得た出席者・説明者情報を突き合わせる。

- ユーザーが「話者A=◯◯」と明示していればそれを使う。
- 明示が無い場合の手がかり:
  - **発話比率が突出して高い話者** = 主たる説明者・進行役の可能性が高い。
    ユーザーが指定した「説明者」と対応づける。
  - **性別ラベル**（男性/女性）で候補を絞り込む。
  - それでも曖昧なら、サマリを提示してユーザーに確認する（推測で確定しない）。
- 確定したマッピングで、トランスクリプトの「話者A」等を実名に置換する。

### 4. 議事録の生成（precise-minute-taking に委譲）

実名化したトランスクリプトと、日時・出席者・説明者の情報をまとめ、
**既存スキル `precise-minute-taking` を呼び出して**議事録を作成する。

`precise-minute-taking` に渡す入力は次の構造でまとめる:

```
# 会議メタ情報
- 日時: <日時>
- 出席者: <氏名一覧>
- 説明者/議題担当: <話題ごとの説明者>

# トランスクリプト（実名・タイムスタンプ付き）
[00:01] 田中: ...
[00:15] 佐藤: ...
...
```

`precise-minute-taking` が利用できない環境の場合のみ、フォールバックとして
このスキル内の簡易テンプレート（末尾参照）で議事録を作り、その旨をユーザーに伝える。

### 5. 保存と確認

- 生成した議事録を `議事録_<日付>.md` として保存する。
- トランスクリプト（`transcript.txt`）も成果物として残す。
- ユーザーに、話者マッピングが正しかったか・議題の粒度が適切かを確認してもらう。

## フォールバック議事録テンプレート

`precise-minute-taking` が見つからない場合のみ使用する最小テンプレート。
（本来は `precise-minute-taking` の詳細フォーマットを優先する）

```markdown
# 議事録

- **会議名**:
- **日時**: <日時>
- **場所 / 形式**:
- **出席者**: <氏名一覧>
- **説明者**: <話題ごとの説明者>

## 議題と議論内容
### 1. <議題>（説明者: <氏名>）
- 要点:
- 議論:

## 決定事項
- [ ]

## アクションアイテム
| 担当 | 内容 | 期限 |
|------|------|------|
|      |      |      |

## 次回予定
-

## 補足 / 備考
-
```
