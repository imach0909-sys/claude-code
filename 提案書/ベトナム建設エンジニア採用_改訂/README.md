# ベトナム優秀建設エンジニア 採用プログラム ご提案（改訂版 / REV.2）

ESUTECH（ESUHAI Technology CO., LTD.）名義の、日本の建設会社様向け採用提案書。
初版（合同イベント経由でのご紹介モデル）が機能しなかったことを受けた改訂版。

## 改訂の理由

初版は、大手ゼネコン向けの採用イベントに集まった建設系大学生（参加56名 / 先行企業の合格枠は最大4名）の
うち、枠から漏れた50〜60名を他の建設会社様へご紹介する設計だった。

結果として、学生の応募動機が「大手ゼネコンで働くこと」に紐づいており、
紹介先の企業へは志望度が引き継がれず、マッチングが成立しなかった。

## 改訂後のモデル

母集団を「余った学生」から集めるのではなく、はじめから貴社を志望する学生として形成する。

1. 提携大学のキャンパスで、貴社単独の会社説明会を開催
2. 貴社名・職務・待遇を明記した告知（3週間）＋ 志望理由つきの事前エントリー制
3. 説明会当日に貴社がご登壇し、個別質問・一次面談まで実施
4. 選考・最終面接 → 内定
5. 奨学金・生活支援金で学習期間（約15ヶ月）を支え、N3合格・CoE発行を経て来日・入社

奨学金・生活支援金のスキーム（学費一部支援 30,000,000〜60,000,000 VND/人、
生活支援金 2,000,000 VND/月、1人あたり総額目安 34万〜54万円）は初版から変更なし。

## 数値の出典

- 56名 / 最大4名 / 50〜60名、支援金額、モデル年収例（30歳 530〜720万円、40歳 800〜1,100万円）、
  提携大学名、JLPT N3 要件 … いずれも初版提案書の記載をそのまま引用
- 「1校あたり参加 30〜50名」「2〜3校で母集団を形成」 … 本改訂で新たに置いた**計画上の目安**。
  実績値ではないため、実施前に実勢に合わせて要確定
- スケジュールの暦月（2026年10月着手の例）… 初版は2026年9〜10月のJPC入学を前提としており
  既に時期を過ぎているため、起点からの相対日程に組み替えたうえでの**例示**
